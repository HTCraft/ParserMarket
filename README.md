# yazsm-parser

Парсер каталога сайта [yazsm.ru](https://yazsm.ru/product/) на Python. Обходит все разделы каталога (вместе со страницами пагинации), находит карточки товаров и сохраняет в CSV (UTF-8) **наименование**, **стоимость** и **ссылку на изображение**, а также ссылку на товар и раздел каталога.

В репозитории только программа: готовые данные не хранятся, файл с товарами создаётся при запуске.

## Возможности

- Обход всего каталога или одного выбранного раздела.
- Определение карточек товаров по структуре страницы, а не по жёстко заданным CSS-классам.
- Поддержка отложенной загрузки изображений (lazy-load) и пагинации (`?PAGEN_1=N`).
- Дедупликация: товар, который встречается в нескольких разделах, записывается один раз.
- CSV в UTF-8 (по умолчанию с BOM, чтобы Excel корректно открывал кириллицу).
- Защита от блокировок (HTTP 403/429, страницы проверки): адаптивные паузы, повторы с задержкой, ротация User-Agent и прокси, автоматический переход на настоящий браузер.
- Безопасная остановка: если сайт блокирует доступ, уже собранные данные всё равно сохраняются.

## Требования

- Python 3.9 или новее (рекомендуется 3.11+)
- Библиотеки: `requests`, `beautifulsoup4`, `lxml`
- Необязательно: `playwright` и любой из браузеров (Microsoft Edge, Google Chrome или встроенный Chromium) для режима браузера

## Установка

```bash
git clone https://github.com/<ваш-аккаунт>/yazsm-parser.git
cd yazsm-parser
```

Создайте и активируйте виртуальное окружение.

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Если PowerShell блокирует запуск скриптов, один раз выполните `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

### Режим браузера (необязательно)

Нужен только если сайт начнёт блокировать обычные запросы (ошибки 403/429, проверка браузера). Без него парсер работает в обычном режиме.

```bash
pip install playwright
```

Скачивать браузер Playwright **не обязательно**: парсер умеет использовать уже установленные в системе Microsoft Edge или Google Chrome (параметр `--browser-channel`). Встроенный Chromium при желании устанавливается командой `playwright install chromium`.

## Быстрый старт

Сначала проверьте работу на одном небольшом разделе:

```bash
python parse_yazsm.py --start https://yazsm.ru/product/borduri/ --out test.csv
```

Если в `test.csv` оказались товары с названием, ценой и ссылкой на изображение, запускайте весь каталог:

```bash
python parse_yazsm.py
```

Результат появится в файле `yazsm_products.csv` в текущей папке.

## Типы запуска

| Задача | Команда |
|---|---|
| Весь каталог | `python parse_yazsm.py` |
| Один раздел | `python parse_yazsm.py --start https://yazsm.ru/product/borduri/` |
| Свой файл результата | `python parse_yazsm.py --out catalog.csv` |
| CSV с разделителем-запятой | `python parse_yazsm.py --delimiter ","` |
| Чистый UTF-8 без BOM | `python parse_yazsm.py --encoding utf-8` |
| Бережный режим (медленнее, реже блокировки) | `python parse_yazsm.py --delay 2` |
| Отладка (сохранить HTML страниц в `debug_html/`) | `python parse_yazsm.py --debug` |
| Не использовать браузер вообще | `python parse_yazsm.py --browser never` |
| Всё через браузер Edge | `python parse_yazsm.py --browser always --browser-channel msedge` |
| Видимое окно браузера (ручное прохождение проверки/капчи) | `python parse_yazsm.py --browser always --headed` |
| Через прокси | `python parse_yazsm.py --proxy http://user:pass@host:port` |
| Список прокси из файла | `python parse_yazsm.py --proxy-file proxies.txt` |

### Запуск из VS Code

Создайте `.vscode/launch.json` и запускайте клавишей `F5`:

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Парсер: один раздел (проба)",
      "type": "debugpy",
      "request": "launch",
      "program": "${workspaceFolder}/parse_yazsm.py",
      "args": ["--start", "https://yazsm.ru/product/borduri/", "--out", "test.csv", "--debug"],
      "console": "integratedTerminal"
    },
    {
      "name": "Парсер: весь каталог",
      "type": "debugpy",
      "request": "launch",
      "program": "${workspaceFolder}/parse_yazsm.py",
      "args": ["--out", "yazsm_products.csv"],
```

Параметр `"console": "integratedTerminal"` нужен, чтобы в режиме `--headed` работал запрос «нажмите Enter».

## Настройка (параметры командной строки)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--start URL` | `https://yazsm.ru/product/` | Раздел, с которого начать. Обход ограничивается этим разделом и его подразделами |
| `--out FILE` | `yazsm_products.csv` | Имя CSV-файла |
| `--delimiter CHAR` | `;` | Разделитель столбцов (`;` удобен для Excel в русской локали) |
| `--encoding ENC` | `utf-8-sig` | Кодировка: `utf-8-sig` (UTF-8 с BOM) или `utf-8` |
| `--delay SEC` | `0.7` | Базовая пауза между запросами; реальная пауза случайная, около ±40% |
| `--max-pages N` | `1000` | Предохранитель: максимум страниц за один запуск |
| `--debug` | выкл. | Сохранять загруженные страницы в папку `debug_html/` |
| `--retries N` | `4` | Число попыток загрузки одной страницы |
| `--max-wait SEC` | `300` | Максимальная пауза между повторами |
| `--max-failures N` | `5` | Сколько страниц подряд могут не загрузиться, прежде чем парсер остановится |
| `--browser MODE` | `auto` | `auto`: подключать браузер при блокировках; `never`: не использовать; `always`: загружать всё через браузер |
| `--browser-channel NAME` | `auto` | `auto`, `chromium`, `msedge`, `chrome`. При `auto` пробуются по очереди встроенный Chromium, Edge, Chrome |
| `--headed` | выкл. | Показывать окно браузера (можно вручную пройти проверку) |
| `--profile-dir DIR` | `.browser_profile` | Папка профиля браузера; cookie сохраняются между запусками |
| `--proxy URL` | нет | Прокси `http://user:pass@host:port`; параметр можно указывать несколько раз |
| `--proxy-file FILE` | нет | Файл со списком прокси, по одному в строке (строки с `#` игнорируются) |

Справка по всем параметрам: `python parse_yazsm.py --help`.

## Формат результата

CSV с заголовком в первой строке:

| Столбец | Содержание |
|---|---|
| Наименование | Название товара, как на сайте |
| Стоимость | Цена в том виде, как показана на сайте, например `от 800 руб./м2` |
| Старая цена | Вторая цена, если она показана в карточке (иначе пусто) |
| Изображение | Полная ссылка на фото товара (`https://yazsm.ru/upload/...`) |
| Ссылка на товар | Адрес страницы товара |
| Раздел | Раздел каталога; если товар есть в нескольких разделах, они перечисляются через ` \| ` |

Цена сохраняется текстом, потому что на сайте она указана в формате «от … руб./м2».

## Как это работает

1. Начиная со страницы `/product/`, парсер собирает ссылки на разделы и страницы пагинации (фильтры, сортировки и страницы самих товаров пропускаются).
2. Каждая страница загружается через модуль `Fetcher` с защитой от блокировок.
3. Карточка товара определяется по структуре: от ссылки-картинки парсер поднимается по HTML-дереву до блока, где есть название товара и признак товара (цена, «В наличии», «Сделать заказ»). Плитки разделов за товары не принимаются.
4. Из карточки извлекаются название, цена (старая цена отделяется по зачёркиванию), изображение (с учётом `data-src`, `srcset`; иконки пропускаются).
5. Результат записывается в CSV. При нажатии `Ctrl+C` или блокировке собранное уже сохраняется.

## Защита от блокировок

- Браузерные заголовки, ротация User-Agent, заголовок Referer, cookie-сессия.
- Случайные паузы; при блокировке паузы автоматически растут (до ×16), при успешных запросах возвращаются к норме.
- Повторы с экспоненциальной задержкой, учитывается заголовок `Retry-After`.
- После каждой блокировки меняется «личность»: новая сессия, другой User-Agent, следующий прокси.
- Распознавание страниц-заглушек (проверка браузера, капча), в том числе при HTTP 200.
- Автоматический переход на настоящий браузер (Playwright) при блокировках; режим `--headed` для ручного прохождения проверки.
- Остановка с сохранением данных, если несколько страниц подряд не загрузились.

Капчу парсер сам не решает: её либо проходят вручную в режиме `--headed`, либо пережидают блокировку.

## Решение проблем

| Симптом | Что делать |
|---|---|
| `ModuleNotFoundError: No module named 'requests'` | Активируйте `.venv` и выполните `pip install -r requirements.txt`. В VS Code выберите интерпретатор из `.venv` (`Ctrl+Shift+P` → Python: Select Interpreter) |
| `python` не найден (Windows) | Используйте `py` вместо `python` или переустановите Python с галочкой Add Python to PATH |
| CSV пустой | Запустите с `--debug` и посмотрите HTML в `debug_html/`. Возможно, изменилась вёрстка сайта или включена защита от ботов |
| Ошибки 403/429 | Парсер замедлится и перейдёт на браузер сам. Для этого должен быть установлен `playwright` и любой из браузеров (Edge, Chrome). Попробуйте `--delay 2` |
| Блокировки при включённом VPN | Запускайте парсер без VPN: многие сайты блокируют иностранные и «облачные» IP |
| Ошибка SSL при `playwright install chromium` | Отключите VPN и повторите. Либо не скачивайте браузер, используйте установленный: `--browser-channel msedge` |
| В Excel вместо русских букв «кракозябры» | Оставьте кодировку по умолчанию `utf-8-sig` или импортируйте файл через «Данные → Из текста/CSV» с кодировкой UTF-8 |
| Не активируется `.venv` в PowerShell | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` либо используйте `cmd` и `.venv\Scripts\activate.bat` |

## Ограничения

- Карточки определяются эвристически. При существенном изменении вёрстки сайта разбор может потребовать правки; для диагностики используйте `--debug`.
- Перед полным запуском выполните пробный запуск на одном разделе и проверьте результат.
- Используйте парсер ответственно: не уменьшайте паузы без необходимости, чтобы не создавать лишнюю нагрузку на сервер, и учитывайте условия использования сайта и его `robots.txt`.
